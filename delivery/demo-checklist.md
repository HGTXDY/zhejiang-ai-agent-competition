# 比赛演示验收清单

> 日期：2026-09-26 版本草案。每次演示前复制一份并填写结果。

## 环境

- [ ] Python 3.12 可用
- [ ] Node.js 20+、npm 可用
- [ ] `./scripts/check-delivery.sh` 通过
- [ ] 不存在真实密钥、个人隐私或未授权数据
- [ ] 浏览器可访问前端地址

## 功能演示

- [ ] 正常四道菜排程可展示
- [ ] 可按资源轨道筛选
- [ ] 可按任务状态筛选
- [ ] 任务详情显示时间窗口、资源和锁定状态
- [ ] 完成任务后状态和进度更新
- [ ] 上报延迟后出现通知
- [ ] 上报设备异常后出现异常提示
- [ ] 临时加菜后出现新增任务
- [ ] 重排差异面板能解释新增、移动、资源变化和锁定任务
- [ ] 可保存或导出排程快照

## 异常与回退

- [ ] 后端不可用时前端明确显示演示模式或错误状态
- [ ] Mock API 失败时不会导致页面白屏
- [ ] 锁定任务不能被非法修改
- [ ] 设备不可用场景返回稳定错误码
- [ ] 无可行排程与求解器未知状态不能混淆

## 交付门禁

- [ ] 所有 PR CI 通过
- [ ] 每个普通代码 PR 都有另一位成员 Review
- [ ] 未将 `fixtures/v1` 宣称为官方 Gold Label
- [ ] README、运行命令、已知限制已更新
- [ ] 演示录屏使用的提交 SHA 已记录
